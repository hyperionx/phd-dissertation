\chapter{Biorealistic Learning Foundations}\label{ch:foundations}

\noindent Spiking neural networks communicate through discrete events, but learning depends on quantities that
persist between them. Synaptic current drives the membrane, the weight stores learned changes, and a volatile state
preserves recent activity for a later update. This chapter defines those three roles and connects each of them to the
persistent and volatile states available in a memristive device.\\

\noindent The chapter's contribution is a common framework for the experimental and simulation results that follow.
It distinguishes persistent weight, volatile synaptic state, measured current, and eligibility; defines how each is
written, held, read, or updated; and separates device physics from the circuitry that converts these quantities into
network computation and learning.

\section[Synaptic Learning from Spike History]{Synaptic Learning from Spike History}\label{sec:spike-history}

\noindent Synapses convert input spikes into current, neurons convert that current into output spikes, and plasticity
either changes the weight or stores activity for a later update. The models retain these functions while omitting
biological detail that the analysis does not use \cite{kandel2000principles}. This section follows that sequence from
spike generation to the persistent and volatile synaptic states, and then to learning from delayed reward.

\subsection[Spiking-Network Abstraction]{Spiking-Network Abstraction}\label{subsec:neuronal-modelling}

\noindent Biological neurons integrate synaptic current and emit action potentials when their membrane voltage
crosses a threshold \cite{mel1994information, johnston1996active}. Hodgkin--Huxley-type models reproduce the
underlying ion-channel kinetics \cite{hodgkin1952quantitative}, but the models used here require only integration,
leakage, thresholding, and reset. A single-compartment model therefore separates spike generation from subthreshold
membrane dynamics \cite{abbott1999lapicque}.\\

\noindent Figure~\ref{fig:2v1} represents the membrane as a capacitance $C$ in parallel with a resistance $R$.
Incoming current charges $C$, while $R$ returns the membrane towards its resting potential in the absence of input.
This circuit gives the leaky integrate-and-fire (\abbrevdef{LIF}) description of the membrane potential
\cite{lapicque1907louis, knight1972dynamics, koch2004biophysics},
\begin{align}
    \tau_{\abbrevdef{RC}} \frac{dV}{dt} = R\,J(t) - V + V_{rest}, \qquad \tau_{\abbrev{RC}} = R\,C, \label{eq:2.1}
\end{align}

\noindent where $J(t)$ is the summed synaptic current, $V_{rest}$ is the resting potential, and
$\tau_{\abbrev{RC}}=RC$ is the membrane time constant. When $V$ reaches the threshold $V_{th}$, the neuron emits a
spike, resets to $V_{rest}$, and remains inactive for a refractory interval. The later simulations set $V_{rest}=0$ and
$V_{th}=1$, giving the normalised form $\tau_m\dot V=J-V$, with $\tau_m=\tau_{\abbrev{RC}}$. The network
architecture fixes which neurons are connected, while the synaptic weights set the strengths of those connections.

\textbf{(a)} Synaptic inputs arrive as spike trains. \textbf{(b)} Each spike contributes a filtered current described

\noindent Every network input must first be represented as spike times. In rate coding, signal intensity sets the
firing rate or spike probability over a presentation window; in latency coding, it sets the time of a spike
\cite{gerstner1997neural, chase2006spike, dayan2005theoretical, eshraghian2023training}. Static images carry no
timing of their own and therefore require an encoder, while event-based sensors produce asynchronous events as their
input changes \cite{amir2017dvsgesture, cramer2020shd}. Moving such a sensor across a static image dataset can give
its samples physical event times \cite{orchard2015nmnist}.\\

\noindent Output spikes must then be converted into a decision, and common readouts take the spike count over the
presentation window, the first-spike latency, or the final membrane potential \cite{eshraghian2023training}.
\emph{Classification accuracy} throughout this thesis is the fraction of samples assigned to the correct class. The
readout determines which part of a time-dependent synaptic response affects that decision: spike counts integrate
across the window, whereas first-spike readout depends most strongly on the early response.

\subsection[Persistent Weight and Temporary State]{Persistent Weight and Temporary State}\label{subsec:plasticity}

\noindent A synapse separates transmission from learning: its persistent weight sets how strongly an input spike
drives the postsynaptic neuron \cite{bastos2022motor}. The same spike also produces a temporary postsynaptic current,
and a separate volatile state can preserve recent activity for a later update. In this thesis, programmed conductance
supplies the persistent weight, and device relaxation supplies the volatile state.\\

\noindent The postsynaptic current extends the effect of a spike beyond its arrival time, and a causal first-order
filter gives the impulse response
\begin{align}
    h(t) = \begin{cases}
    \dfrac{1}{\tau_s}\, e^{-t/\tau_s}, & t \ge 0, \\[4pt]
    0, & t < 0,
\end{cases} \label{eq:2.2}
\end{align}

\noindent where $\tau_s$ sets the duration of the current and $h(t)=0$ for $t<0$ enforces causality. Convolving the
presynaptic spike train with $h(t)$ gives the current $J(t)$ in Equation~\ref{eq:2.1}, as shown in
Figure~\ref{fig:2v1}(b). An alpha function can reproduce measured postsynaptic currents more closely
\cite{mainen1995reliability}, but the first-order filter is sufficient for the network abstraction used here. This
time constant $\tau_s$ therefore sets how long a single spike drives the neuron, while the volatile state treated
below keeps a lifetime of its own.\\

\noindent Local plasticity rules act on the persistent weight, and spike-timing-dependent plasticity
(\abbrev{STDP}) strengthens or weakens a synapse according to the order of its pre- and postsynaptic spikes
\cite{zheng2018learning, markram1997regulation}. In memristive pulse pairing, the pulse amplitudes and their relative
timing set the voltage across the device, whose nonlinear response produces the conductance change. Both forms use
signals available at the synapse and apply the update at the spike coincidence. Because the conductance changes at
that coincidence, delayed evaluation requires an additional volatile state.

\subsection[Delayed Reward and Eligibility]{Delayed Reward and Eligibility}\label{subsec:learning-paradigms}

\noindent Reinforcement learning trains an agent from the consequences of its actions. The agent observes a state,
selects an action according to its policy, and receives a scalar reward that evaluates the outcome
\cite{sutton2018reinforcement}. Because that reward may arrive after the synaptic activity that produced the action has
ended, temporal credit assignment asks which earlier activity contributed to the outcome and should therefore change.
This is the distal-reward problem of a spiking network \cite{izhikevich2007solving}: the relevant spikes have passed
before the reward arrives.\\

\noindent An eligibility trace preserves the missing local information: pre--post activity writes a temporary state
$e_{ij}$ at the synapse from neuron $i$ to neuron $j$, without immediately changing its weight. In the canonical
neo-Hebbian rule \cite{fremaux2016neuromodulated, gerstner2018eligibility}, that state follows
\begin{align}
    \frac{de_{ij}}{dt} = -\frac{e_{ij}}{\tau_e} + c_{ij}(t), \label{eq:2.3}
\end{align}

\noindent where $c_{ij}(t)$ is the local coincidence signal and $\tau_e$ is the eligibility decay time. In this
canonical form, $\tau_e$ is a chosen single-timescale model parameter; the device-based model developed in this
thesis instead takes its decay profile from a measured relaxation.\\

\noindent A delayed scalar signal then converts the surviving eligibility into a persistent weight change,
\begin{align}
    \Delta w_{ij} = \eta\,(R - b)\, e_{ij}(t_R), \label{eq:2.4}
\end{align}

\noindent evaluated when reward $R$ arrives at time $t_R$. The running baseline $b$ estimates expected reward, so
$R-b$ indicates whether the outcome was better or worse than expected, and the learning rate $\eta$ scales the update
\cite{sutton2018reinforcement}. Presynaptic and postsynaptic activity form $c_{ij}(t)$, while the
broadcast reward supplies the third factor, and at reward Equation~\ref{eq:2.4} scales each synapse's update by
the eligibility that survives to $t_R$.\\

\noindent The decay time $\tau_e$ sets how long spike history remains available to reward, bridging millisecond
spikes and slower behavioural outcomes \cite{florian2007reinforcement}. This time constant serves a different function
from the other network time constants: $\tau_s$ shapes the postsynaptic current, $\tau_m$ sets membrane leakage, and
$\tau_e$ sets the interval over which activity remains eligible for learning. Figure~\ref{fig:2v2} shows the resulting
sequence of coincidence, decay, and reward-gated update.\\

\noindent Both the local tag and the delayed broadcast of this rule have functional precedents in biology. In synaptic
tagging and capture, activity leaves a temporary molecular tag at the stimulated synapse, and later plasticity-related
products stabilise a change while that tag persists \cite{frey1997synaptic, redondo2011making}. Diffuse dopamine
release supplies the corresponding precedent for the delayed broadcast signal
\cite{fremaux2016neuromodulated, gerstner2018eligibility}. These correspondences are functional: biological tags
involve calcium- and protein-based processes lasting minutes to hours, and no shared chemistry or timescale with the
device state is assumed.

\caption[Three-factor learning and the eligibility trace.]{Canonical three-factor learning sequence.
\textbf{(a)} A pre--post spike coincidence occurs at the synapse. \textbf{(b)} That coincidence writes an eligibility

}

\noindent Eligibility retains the synapse-specific information that a scalar reward lacks
\cite{he2015eligibility, shindou2019silent}. It addresses temporal credit at each synapse while leaving a separate
spatial-credit problem, because the reward does not identify how hidden neurons contributed to the outcome
\cite{lillicrap2016random, sacramento2018dendritic}. A physical eligibility state must therefore remain local,
survive until reward, and be available to the circuit that applies the persistent update
\cite{demirag2021pcmtrace, sarwat2022chalcogenide}.

\section[Physical Requirements for Storing Spike History]{Physical Requirements for Storing Spike
History}\label{sec:physical-requirements}

\noindent Memristive SiO$_x$ enters a learning system through two distinct physical quantities. Non-volatile
switching stores programmed conductance as a persistent weight, while subthreshold relaxation provides a temporary
state that preserves recent activity. The evidence assigns these roles to different device families and
preparation routes, and the analysis treats them as separate quantities. In both regimes, current is measured while the
internal state must be inferred, so transport physics links the electrical readout to the physical state.

\subsection[Memristive State and Operating Regimes]{Memristive State and Operating
Regimes}\label{subsec:regimes}

\noindent A memristive device is a two-terminal element whose present current depends on the applied voltage and
its electrical history \cite{chua1971memristor, strukov2008missing}, with an internal state $s$ representing that
history.
At circuit level, a conduction law gives the current from the present state and voltage, while a state equation
describes how the state evolves,
\begin{align}
    I = g(s, V), \qquad \frac{ds}{dt} = f(s, V), \label{eq:2.5}
\end{align}

\noindent Here, $g(s,V)$ gives the terminal current and $f(s,V)$ gives the rate of state change; the symbol $w$
denotes a synaptic weight throughout the network and learning chapters, and carries a subscripted index elsewhere
only where it labels the coefficients of a fitted expansion. The state $s$ may represent oxygen-vacancy concentration, trapped-charge occupancy,
or filament extent. Device structure and operating conditions determine the forms of $g$ and $f$, which electrical
measurements constrain through the terminal current. Use of \emph{memristive} follows the broader
resistance-switching sense, because real cells include ionic and thermal dynamics beyond the ideal charge--flux
relation \cite{chua2019resistance}.\\

\noindent In the non-volatile regime, an applied bias above the switching threshold changes the dominant state, and
that change remains after the bias is removed. Resistive switching is therefore a reversible change
between a high-resistance state (\abbrevdef{HRS}) and a low-resistance state (\abbrevdef{LRS})
\cite{mehonic2018silicon, liu2010controllable}. A one-time electroforming step converts the pristine film into a
switchable cell, and thereafter Set changes the device from \abbrev{HRS} to \abbrev{LRS} while Reset returns it to
\abbrev{HRS}. Devices with an insulating active layer, typically a metal oxide, between two electrodes form the
resistive random-access memory (\abbrevdef{RRAM}) family \cite{wang2017memristors}. Because the programmed state
remains without power, its conductance can represent a persistent synaptic weight.\\

    \centering
    \includegraphics[width=0.9\textwidth]{Chapter2/Figs/rram_types.png}
    \caption[The main RRAM types.]{The main \abbrev{RRAM} types, from left to right: electrochemical
    metallisation memory (\abbrevdef{ECM}), in which a filament of metal cations (e.g. Ag$^+$) bridges the
    electrodes; valence change memory (\abbrevdef{VCM}), in which the filament forms from oxygen vacancies in the
    oxide (highlighted); and thermochemical memory (\abbrevdef{TCM}), driven by local Joule heating
    \cite{goux2016electrochemical, liu2015categorization}.}
    \label{fig:2g}
\end{figure}

\noindent Below the switching threshold, stimulation changes a volatile component of the state without producing
the persistent transition. This component relaxes after the stimulus ends, so the conductance retains recent activity
for a finite interval. Similar volatile conductance changes occur in other material systems
\cite{chang2011shortterm, ohno2011shortterm} and are measured in the silicon-oxide devices studied here. This subthreshold
relaxation supplies the fading volatile state required for delayed reward in
Subsection~\ref{subsec:learning-paradigms}.

\subsection[Transport and Trapping]{Transport and Trapping}\label{subsec:transport}

\noindent Terminal current is the measured quantity, and the internal device state is inferred from it rather than
observed directly. Transport analysis relates a change in that current to the state that may preserve recent
activity. \emph{Electrode-limited} mechanisms depend on the injection barrier at the metal--oxide interface, whereas
\emph{bulk-limited} mechanisms depend on the oxide interior and its defects \cite{sze2021physics}. Each class predicts a characteristic dependence
on voltage, field, or temperature. The measured data are tested against these predictions using linearised plots and
physically admissible fitted parameters. Figure~\ref{fig:2j} illustrates the energy-band diagrams of the principal
electronic candidates.\\

\noindent Table~\ref{table:2trans} lists the candidate mechanisms, their current-density equations, and their
simplified voltage and temperature dependences. The measured variables are current density $J$, field $E$, applied
voltage $V$, and absolute temperature $T$. The material parameters are barrier thickness $d$, barrier height
$\phi_B$, trap depth $\phi_t$, effective mass $m^*$, permittivity $\varepsilon_i$, carrier mobility $\mu$, and the
electronic and ionic activation energies $\Delta E_a$ and $\Delta E_{a,ion}$. The remaining symbols are physical
constants or grouped factors: $q$, $k_B$, $\hslash$, $A^{**}$, $a$, and $b_1$ to $b_3$, with
$c=\Delta E_a/k_B$ and $c'=\Delta E_{a,ion}/k_B$. Where a simplified expression carries no explicit $T$, that model
predicts no temperature dependence.\\

\noindent Each candidate mechanism predicts a straight line in particular linearised coordinates, and the measured
data are tested against that prediction. Poole--Frenkel emission gives a straight line for $\ln(J/E)$ against
$\sqrt{E}$, whose slope gives a relative permittivity. Trap-assisted tunnelling gives a straight line for $\ln J$
against $1/E$, whose slope gives a trap depth, while Fowler--Nordheim tunnelling is linear in $\ln(J/E^2)$ against
$1/E$. Linearity alone does not identify a mechanism: the parameter obtained from the slope must also be physically
plausible. This second criterion rejects a Poole--Frenkel fit implying a relative permittivity below unity. Direct
tunnelling depends exponentially on barrier width and is negligible across the full 25 to 35\,nm oxide thickness
used here.\\

\noindent In a trap-mediated conduction model, terminal current varies with the concentration of occupied traps, so
gradual trap filling or release produces a gradual change in measured current
\cite{many1962theory, houng1999current}. Ionic redistribution can also change the current by modifying the internal
field, even when electronic carriers cross the device \cite{waser2009redox, meyer2005oxygen}. This ionic contribution
lies outside an electronic-current fit, which therefore cannot recover the activation energy for ionic hopping
\cite{bucci1966ionic}, and the electrode material may determine which contribution appears in the measured response
\cite{ge2014electrode}. Because the SiO$_x$ contacts contain no active-metal source, vacancy redistribution is used
as a working interpretation, while the mobile species remains unidentified
\cite{mehonic2015structural, kenyon2019interplay}.

\subsection[Required Operations and Timescales]{Required Operations and Timescales}\label{subsec:subthreshold}

\noindent A volatile state must support three operations in sequence: a write, an input-free hold, and a later read
\cite{chang2011shortterm, ohno2011shortterm, zhang2017emulating}. Writing changes the state, which then relaxes without
further input for the duration of the hold. A small read probe returns an electrical quantity that depends on the
elapsed hold time, so the decay itself can be measured \cite{covi2021switching}.\\

\noindent These operations give the volatile state a specific role in delayed learning. Local spike activity writes
the state, the delay to reward provides the hold interval, and reward-gated circuitry uses the surviving state to
change the persistent weight. Figure~\ref{fig:2v3} places that sequence beside the non-volatile case, in which one
programmed conductance holds a weight indefinitely. Eligibility must survive until reward arrives, while the updated
weight must remain afterwards; the present work does not establish both functions in one physical device.\\

\centering
\includegraphics[width=\textwidth]{Chapter2/Figs/fig2_persistent_volatile.pdf}
\caption[Persistent and volatile memristive state.]{Two operating roles of memristive state. \textbf{(a)} An
above-threshold write produces a persistent conductance $G$ that stores a weight. \textbf{(b)} A subthreshold write
produces a volatile state that decays during an input-free hold, so the later read depends on the elapsed time.
}
\label{fig:2v3}
\end{figure}

\noindent The learning task sets the interval that the state must bridge, and the material supplies the realised
lifetime. Individual spikes last about a millisecond, while an action may be evaluated seconds later
\cite{gerstner2018eligibility}. A volatile state must therefore outlast the membrane
response without becoming persistent, covering the interval over which dopamine can reinforce a recently stimulated
synapse \cite{yagishita2014timewindow, he2015eligibility}. Measurement of the relaxation that follows a subthreshold
write shows whether a given device supplies that interval.\\

\noindent The decay profile matters as well as its timescale: mean lifetime is the area beneath a normalised decay,
but two profiles with the same area can retain different fractions of state at a given reward delay. Disordered
materials can release charge over a distribution of rates and therefore relax non-exponentially
\cite{scher1975anomalous, kakalios1987stretched}. These profiles must consequently be measured in full and under
stated conditions, because their shape changes the retained state and the resulting temporal credit
\cite{legallo2018collective, zhang2024mesoporous}.\\

\noindent Trap occupancy and space charge provide two candidate physical states behind a relaxing conductance.
Trapping and release alter the population of occupied traps and therefore the trap-mediated current, with the decay
set by the distribution of release energies \cite{lang1974deep, libsch1993bias}. Space charge instead changes the
internal field and can persist after the applied field is removed \cite{el2006space, boikov2002near}. Because
terminal current may contain both contributions, the transient measurements must test which interpretation the
observed voltage and time dependence support.

\section[From Device State to Learning System]{From Device State to Learning
System}\label{sec:neuro-hardware}

\noindent Arrays and peripheral circuits assign each device a system-level function
\cite{mead1989analog, ceolini2020hand}. The crossbar maps positive conductances onto weighted sums, while peripheral
circuits recover signed results, generate spikes, and apply updates. Where the update is calculated then
determines whether device physics constrains a trained network or participates directly in learning.

\subsection[Crossbar Computation and Weight Mapping]{Crossbar Computation and Weight
Mapping}\label{subsec:crossbar}

\noindent A crossbar stores one conductance at each intersection of its word and bit lines. Applying a voltage vector
to the word lines produces crosspoint currents that sum along the bit lines,
\begin{align}
    \mathbf{I} = \mathbf{G}\,\mathbf{V}, \label{eq:2.6}
\end{align}

\noindent where $\mathbf{V}$ is the applied voltage vector, $\mathbf{G}$ is the conductance matrix, and $\mathbf{I}$
is the resulting bit-line current vector. Ohm's law supplies each product, and Kirchhoff's current law supplies the
sum. The array therefore performs the matrix--vector product of a network layer in one physical operation
\cite{hu2016dot, xia2019memristive}.\\

\noindent Device conductance is positive and bounded by $[G_{off},G_{on}]$, while a network weight can be positive
or negative. A differential pair represents the sign by placing two conductances on separate bit lines
\cite{joksas2022nonideality},
\begin{align}
    w \propto G^{+} - G^{-}, \label{eq:2.7}
\end{align}

\noindent where $G^+$ and $G^-$ encode the positive and negative parts of the weight. Choosing the pair symmetrically
about a mean conductance uses the available range on both devices \cite{kim20214k}, and placing the two devices close
together limits differences in line resistance \cite{joksas2020committee}. Figure~\ref{fig:2v4} shows the resulting
mapping, in which each logical synapse occupies two crosspoints on adjacent bit lines.\\

\begin{figure}[htbp!]
\centering
\includegraphics[width=\textwidth]{Chapter2/Figs/fig2_crossbar_state.pdf}
\caption[Crossbar computation with persistent and volatile synaptic quantities.]{A crossbar with differential
conductance pairs. Input voltages produce currents $VG$ that sum along each bit line, and subtracting the paired
currents gives the signed contribution $V(G^+-G^-)$. The volatile state $s_{ij}$ belongs to the same logical synapse
but may be supplied by a separate physical element.}
\label{fig:2v4}
\end{figure}

\noindent A presynaptic spike reaches the word line as a voltage pulse. Each conductance scales that pulse, the
bit-line current sums the crosspoint contributions, and a subtraction circuit recovers the signed result from the two
columns. A neuron circuit integrates this current and generates the spikes sent to the next layer, so the array
follows the biological sequence of presynaptic spike, postsynaptic current, and output spike
\cite{kandel2000principles, koch2004biophysics}. Row drivers, subtraction circuits, and neuron circuits therefore
form part of the computing path, although their physical implementation lies outside the present scope.\\

\noindent Programmed conductance and volatile state remain separate variables at each logical synapse. Conductance
stores the persistent weight, while recent activity sets a temporary state that can modulate transmission until it
relaxes. These two variables may be carried by separate physical elements, and they constrain a network in different
ways: static conductance non-idealities affect the weight mapping, whereas volatile relaxation determines how long the
temporary state remains available.

\subsection[Hardware-Aware and Local Learning]{Hardware-Aware and Local Learning}\label{subsec:hardware-aware}

\noindent Device physics can determine an immediate weight update at the cell itself. Pulse-pairing schemes make that
dependence explicit: the pre- and postsynaptic neurons apply the same voltage waveform to opposite terminals, and
their relative timing sets the net device voltage \cite{campbell2016pulse},
\begin{align}
    V_{dev}(t) = V_{pre}(t) - V_{post}(t - \Delta t), \qquad \Delta t = t_{post} - t_{pre}. \label{eq:2.8}
\end{align}

\noindent Here, $\Delta t$ is the postsynaptic spike time relative to the presynaptic spike, and it changes the
overlap, amplitude, and duration of $V_{dev}$. The nonlinear device response converts that waveform into a
timing-dependent conductance change, so the device supplies the immediate weight update. Delayed reward
requires an additional operation: recent activity must first write a fading state that remains available when reward
later gates the persistent update.\\

\noindent Hardware-aware offline training and local in-device learning differ in where the update is calculated.
Offline training includes measured device behaviour in the network model and calculates the weight changes in
software through backpropagation, while in-device learning forms the update from signals available at the physical
synapse. Both routes are used here: the first tests trained networks under measured device dynamics, and the second
tests reward-modulated local learning.\\

\noindent Both routes must accommodate device variation, which enters in several distinct forms: conductance updates
may be nonlinear or asymmetric, nominally identical cells may differ in range and threshold, read noise limits
resolution, and volatile state changes after writing. The available corrections are calibration and closed-loop
write-and-verify, which improve programming precision at the cost of additional time. These corrections act at the
device level, and network activity can still drift once they are applied, so homeostatic regulation provides a separate
control by keeping firing within a functional range \cite{turrigiano1999homeostatic}.\\

\noindent Local synaptic updates determine where a weight changes, but a hidden neuron does not directly know
how its activity affected the network output. Backpropagation assigns that spatial credit by sending the output error
through the transpose of the downstream weight matrix. The required copy of the forward weights creates the
weight-transport problem, and feedback alignment replaces the transpose with a fixed random projection, giving
\begin{align}
    \boldsymbol{\delta}^{hidden} = \begin{cases}
    \mathbf{W}^{\top} \boldsymbol{\delta}^{out}, & \text{backpropagation}, \\[2pt]
    \mathbf{B}\, \boldsymbol{\delta}^{out},      & \text{feedback alignment},
\end{cases} \label{eq:2.9}
\end{align}

\noindent where $\boldsymbol{\delta}^{out}$ is the output error, $\mathbf{W}$ is the forward weight matrix, and
$\mathbf{B}$ is a fixed random matrix with the shape of $\mathbf{W}^{\top}$. No known biological mechanism supplies
an exact transported copy of the forward weights \cite{grossberg1987competitive}. Feedback alignment avoids that
copy \cite{lillicrap2016random}, and direct feedback alignment sends the projected error directly to each hidden
neuron \cite{nokland2016direct}. This projected feedback remains neuron-specific, even though it no longer depends on
the downstream weights.\\

\noindent Existing hardware assigns device physics several learning functions, and phase-change and mixed-signal
systems perform reward-modulated weight updates locally \cite{bianchi2020bio, bohnstingl2019learns}. An analogue
oxide network programs persistent weights through explicit voltage pulses \cite{portner2025actorcritic}, while a
second-order oxide device uses its internal state to modulate the learning rate \cite{ming2026oxygen}. These systems
provide persistent storage, immediate updates, or control of the rate of plasticity.\\

\noindent Physical eligibility supplies the temporary state needed before the update, and two relaxation processes
have already been used this way. Phase-change resistance drift has been mapped onto eligibility decay
\cite{demirag2021pcmtrace}, and ferroelectric polarisation relaxation has served as an eligibility state in spiking
reinforcement learning \cite{wang2026ferroelectric}. In this role, device physics preserves recent activity through
the reward delay instead of writing the persistent weight immediately.

\section[Summary]{Summary}\label{sec:2p4}

\noindent Memristive SiO$_x$ supplies two learning variables: non-volatile conductance stores a persistent weight,
and subthreshold relaxation preserves recent activity. This volatile state must support write, hold, and read
operations, and it must survive the relevant delay. Its measured decay profile therefore specifies the state, because
that profile determines what remains.\\

\noindent Crossbar circuits map conductance pairs onto signed weights and convert spikes into neural output.
Hardware-aware training includes measured device behaviour but calculates the updates in software, while local
reward-modulated learning keeps the activity trace at each synapse, broadcasts reward, and avoids weight transport.
Biorealistic learning connects these system requirements to intrinsic material dynamics.
