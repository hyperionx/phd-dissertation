\chapter{Hardware-Aware Spiking Networks}\label{ch:bio}

\noindent Within a crossbar, the current--voltage response sets how each presynaptic spike is transmitted, while
volatile relaxation sets how much state from earlier activity survives until the next spike. This chapter first
trains dense and convolutional spiking networks through the measured static nonlinearity and device variation. That
same relaxation, measured in full, then enters the simulations as a volatile synaptic state, and the experiments test
delayed classification, decay shape, and the distribution of retained state across layers.\\

\noindent Measurements from the electroformed Ti/Au family give the static current response that performs the
weighted sum, and the \abbrev{ITO} measurements give the temporal state that decays between events: distinct
physical quantities, not competing versions of one. The hardware-aware TensorFlow platform was developed within the
group \cite{joksas2022nonideality}; the author reimplemented it in PyTorch, extended it to spiking networks, and
developed the homeostatic regulariser, volatile-state model, and delayed-classification experiments. Because the two
families are combined only within the simulation, this chapter reports a constructed synaptic model driven by
measured device characteristics, not a hardware implementation containing both functions.

\section[Network and Device Model]{Network and Device Model}\label{sec:6p1}

\noindent Simulating a memristive spiking network requires a neuron model, a differentiable training rule, and a
mapping from numerical weights to measured device current. The first subsection defines the discrete spiking dynamics,
input encoding, and readout, and the second maps signed weights onto differential conductance pairs and embeds the
measured nonlinear current response and device variation in the forward pass.

\subsection[Spiking Dynamics and Training]{Spiking Dynamics and Training}\label{sec:6p1p1}

\noindent Every network in this chapter uses the discrete leaky integrate-and-fire (\abbrev{LIF}) neuron introduced in
Section~\ref{subsec:neuronal-modelling}. For postsynaptic neuron $j$, the binary presynaptic spike $x_i(t)$ is
weighted by $w_{ij}$ and added to the membrane potential $V_m$, which otherwise decays towards rest. A unit-step
forward-Euler update gives
\begin{align}
    V_m(t) = V_m(t-1) + \sum_{i} w_{ij}\, x_i(t-1) - \frac{V_m(t-1)}{\tau_m} \label{eq:6.1}
\end{align}

\noindent This update is equivalent to a multiplicative decay factor $\lambda_m=1-1/\tau_m$, and all networks use
$\lambda_m=0.95$, corresponding to $\tau_m=20$ timesteps, with the normalised firing threshold fixed at $V_{th}=1$.
A neuron emits a spike when $V_m>V_{th}$ and subtracts the threshold from its membrane, preserving any excess voltage
and permitting spikes on successive steps (Figure~\ref{fig:6c}). This neuronal time constant is a simulation
hyperparameter; the measured volatility acts at the synapse and remains separate from it.\\

\begin{figure}[htbp!]
    \centering
    \includegraphics[width=\textwidth]{Chapter6/Figs/snn_schematic_vector.pdf}
    \caption[Schematic illustration of a single-layer spiking neural network (SNN).]{\emph{Schematic}: discrete
    \abbrev{LIF} dynamics. \textbf{(a)} Weighted input spikes drive an output neuron. \textbf{(b)} The membrane
    integrates those inputs, decays between them, and emits a spike on crossing threshold. The threshold is then
    subtracted from the membrane. The schematic uses $\lambda_m=0.86$ for visibility; the simulations use $0.95$.}
    \label{fig:6c}
\end{figure}

\noindent Each sample occupies a fixed window, and all membrane states are reset at its start. Static experiments use
the timestep only as a simulation index, whereas the temporal experiments assign it the measured sampling interval.
Real-valued inputs use rate coding \cite{gerstner1997neural}: at each step, an input
spikes with probability equal to its normalised amplitude. The expected spike count is therefore proportional to the
input, while repeated presentations capture the variation introduced by the stochastic encoding.\\

\noindent In every experiment, the predicted class is the output neuron with the largest spike count over the read
window. Static classification optimises cross-entropy from the membrane output at each timestep; the homeostasis and
delayed-memory experiments instead optimise the summed output counts,
\begin{align}
    \mathcal{L} = -\log \frac{\exp\!\big(\textstyle\sum_t x_c(t)\big)}
                              {\sum_{c'} \exp\!\big(\textstyle\sum_t x_{c'}(t)\big)},
    \label{eq:6ratece}
\end{align}

\noindent for true class $c$. This objective trains the same count used for the decision. Exact ties are resolved by
the final membrane potential among the tied classes in Section~\ref{sec:6p3p3}, with chance tie-breaking reported
where it changes the result.\\

\noindent A binary spike has no useful derivative for gradient descent, so the backward pass uses a surrogate
\cite{neftci2019surrogate, zhou2022memristive, pfeiffer2018deep, wang2020supervised}. For the distance from threshold,
$u=V_m-V_{th}$, dense networks use an arctangent derivative and convolutional networks use a fast sigmoid:
\begin{align}
    \frac{\partial x}{\partial u}\bigg|_{\mathrm{dense}} = \frac{1}{1 + (\pi u)^2},
    \qquad
    \frac{\partial x}{\partial u}\bigg|_{\mathrm{conv}} = \frac{1}{(1 + 25\,|u|)^2}.
    \label{eq:6surrogate}
\end{align}

\noindent Both surrogates equal one at threshold and decrease away from it without altering the forward spike
calculation. Backpropagation through time applies the surrogate at each step
\cite{werbos1990backpropagation}, and the differentiable device-current model remains in the same computational
graph, so training accounts for its voltage dependence and fixed device-to-device variation
\cite{joksas2022nonideality, rasch2021flexible}.

\subsection[Conductance Mapping and Device Current]{Conductance Mapping and Device
Current}\label{sec:6p1p2}

\noindent Each signed network weight is mapped to a pair of non-negative conductances. A presynaptic spike applies a
row-voltage pulse, the two devices produce opposing currents, and subtraction of the paired column currents gives the
signed synaptic contribution. Column currents then sum and drive the next \abbrev{LIF} layer. These simulations
include the measured nonlinear current--voltage response and fixed device variation, and omit line resistance, driver
and neuron circuits, stuck-at faults, and random telegraph noise (\abbrevdef{RTN}), each of which would require
separate circuit or programming mitigation
\cite{ambrogio2018equivalent, li2018analogue, xia2017stuck, chen2017accelerator,
jain2019cxdnn, wang2020ssm, li2019build}.\\

\begin{figure}[htbp!] 
\centering    
\includegraphics[width=1\textwidth]{Chapter6/Figs/siox_state_sweeps.pdf}
\caption[Single sweeps of 53 resistance states of a SiO$_x$ device.]{\emph{Measured}: current--voltage sweeps from 53
resistance states of one electroformed Ti/Au-contacted SiO$_x$ device. Increasing the maximum sweep voltage in
$0.05$-V steps produced successive states; colour denotes their order \cite{Barmpatsalos2021-yn}.}
\label{fig:6g}
\end{figure}

\noindent Measurements for the static device model come from 53 current--voltage sweeps of one electroformed
Ti/Au-contacted SiO$_x$ device of the family defined in Section~\ref{sec:matstack}, where incrementally increasing the
maximum sweep voltage produced the resistance states of Figure~\ref{fig:6g}. These 53 sweeps are a separate evidence
unit from the 53 accepted \abbrev{ITO} relaxation fits of Chapter~\ref{ch:model}, which come from a different device
family and a different measurement. Conventional training treats an input
$x_i$ and weight $w_{ij}$ as a linear product,
\begin{align}
y_j = f\left( \sum_{i=1}^{M} x_i\, w_{ij} \right) \label{eq:6.23}
\end{align}

\noindent whereas hardware-aware training replaces that product with a differentiable device function $g$
\cite{joksas2022nonideality}:
\begin{align}
y_j = f\left( \sum_{i=1}^{M} g\left( x_i, w_{ij} \right) \right) \label{eq:6.24}
\end{align}

\noindent Throughout, the signed network weight $w_{ij}$ remains distinct from the conductances $G_+$ and $G_-$ that
encode it. When the two sides are optimised independently, their non-negative numerical weights are denoted
$W_{ij}^{\pm}$. Scaling factors $k_V$ and $k_I$ map network signals to device voltage and current, while $k_G$ maps
numerical weights into the conductance window:
\begin{align}
V    &= k_V\, x \label{eq:6.25} \\
y    &= \frac{I}{k_I} = \frac{I}{k_V k_G} \label{eq:6.26} \\
k_G  &= \frac{G_{max} - G_{min}}{\max |\mathbf{W}|} = \frac{G_{on} - G_{off}}{\max |\mathbf{W}|} \label{eq:6.27}
\end{align}

\noindent Here $G_{on}$ is the most conductive measured state in Figure~\ref{fig:6g}. Setting the lower mapping
boundary to $G_{off}=G_{on}/5$ is a simulation choice, and the measured states extend below it. This interval,
$[G_{off},G_{on}]$, therefore defines the conductance budget available to each differential pair.\\

\noindent One possible mapping places the two conductances symmetrically around their average:
\begin{align}
G_{\pm}  &= G_{avg} \pm \frac{k_G w}{2} \label{eq:6.28} \\
G_{avg}  &= \frac{G_{off} + G_{on}}{2} \label{eq:6.29}
\end{align}

\noindent Instead, the mapping used here trains two non-negative weights independently and subtracts their device
outputs \cite{joksas2022nonideality, kendall2020training}:
\begin{align}
y_j = f\left( \sum_{i=1}^{M} \left[ g\left( x_i, W_{ij}^+ \right) - g\left( x_i, W_{ij}^- \right) \right] \right) \label{eq:6.32}
\end{align}

\noindent These paired non-negative weights map linearly onto $G_+$ and $G_-$:
\begin{align}
G_{\pm} = k_G W_{\pm} + G_{off} \label{eq:6.33}
\end{align}

\noindent Every result in this chapter uses Equation~\ref{eq:6.33}, because independent mapping allows both
conductances to span the full window, while the symmetric scheme confines small weights near $G_{avg}$ and leaves the
extremes inaccessible. Each mapped conductance then enters the measured nonlinear device model in the forward pass.
A two-point ratio summarises departure from Ohmic behaviour:
\begin{align}
\gamma \equiv \frac{G(2 V_{ref})}{G(V_{ref})} = \frac{I(2 V_{ref})}{2\,I(V_{ref})},
\qquad G(V) \equiv \frac{I(V)}{V} \label{eq:6.34}
\end{align}

\noindent This ratio equals unity for Ohmic conduction \cite{lentz2013current}, and it summarises each measured sweep
without defining the forward model, because two points cannot represent the full voltage dependence of
Poole--Frenkel emission or trap-assisted tunnelling \cite{sung2018effect}. Its role is therefore descriptive, and
every network calculation uses the complete fitted response derived below.\\

\begin{figure}[htbp!] 
\centering    
\includegraphics[width=1\textwidth]{Chapter6/Figs/siox_pf_nonlinearity.pdf}
\caption[Nonlinearity of the measured SiO$_x$ conductance.]{\textbf{(a)} \emph{Measured}: conductance of
53 states, normalised at $V_{\mathrm{ref}}=0.25$~V and coloured by $R(0.1\,\mathrm{V})$. The dashed line is Ohmic;
the screen rejects four states. \textbf{(b)} \emph{Measured and derived}: $\gamma$ against resistance for the 49
retained states, with the Poole--Frenkel fit and mapped conductance window. Measured $\gamma$ rises with resistance,
$\rho=+0.76$, while the fit falls, $\rho=-0.94$.}
\label{fig:6h}
\end{figure}

\noindent A curvature screen removes four sweeps containing abrupt current jumps: for each sweep, the maximum second
numerical derivative divided by mean current must remain below $0.1$, leaving 49 states for fitting. Their measured
nonlinearity generally increases with resistance, although individual states scatter around that trend
(Figure~\ref{fig:6h}). A static conductance perturbation cannot reproduce this voltage dependence, and a lookup table
would expose training to only one measured device instance. The forward model therefore uses the differentiable
Poole--Frenkel form \cite{joksas2022nonideality}, with uncertain pre-exponential factor $c$ and
thickness--permittivity product $d\varepsilon$:
\begin{align}
I = c V \exp\left( \frac{2e}{k_B T} \sqrt{\frac{e V}{4\pi d \varepsilon}} \right) \label{eq:6.37}
\end{align}

\noindent Here $T=20^\circ$C, and $c$ and $d\varepsilon$ are fitted from each measured state. Smaller
$d\varepsilon$ produces a steeper nonlinear response, while large values approximate Ohmic conduction. That
algebraic limit has no microscopic interpretation because Poole--Frenkel transport applies near and below the
conductance quantum, $G_0=2e^2/h\approx77.5\,\mu$S. These fitted parameters therefore provide a stochastic forward
model of measured current variation, not a physical reconstruction of every resistance state
\cite{joksas2022memristive}.\\

\noindent Combining the paired conductance mapping with Equation~\ref{eq:6.37} gives the network-scaled device
function
\begin{align}
g\left( x, W_\pm \right) = \frac{c(W_\pm)\, (k_V x)}{k_V k_G} \exp\!\left( \dfrac{2e}{k_B T} \sqrt{\dfrac{e k_V x}{4\pi\, d\varepsilon(W_\pm)}} \right) \label{eq:6.38}
\end{align}

\noindent whose two coefficients follow from the measured states by a paired regression on conductance,
\begin{align}
\begin{bmatrix} \ln c \\ \ln (d\varepsilon) \end{bmatrix} = -\mathbf{m}\, \ln\left( k_G W_\pm + G_{off} \right) + \mathbf{b} + \mathbf{E} \label{eq:6.39}
\end{align}

\noindent Here $g$ returns $I/(k_Vk_G)$, and $k_V=2V_{ref}$ matches the upper voltage used in
Equation~\ref{eq:6.34}. Both vectors $\mathbf{m}$ and $\mathbf{b}$ are fitted from the 49 retained states, and the
correlated residual $\mathbf{E}$ is drawn once for each simulated synapse and held fixed throughout a run, so
nominally identical conductances differ while each simulated device remains internally consistent. Each input spike
therefore selects a conductance pair, the stochastic model returns its nonlinear differential current, and that
current enters the \abbrev{LIF} update.

\section[Static Hardware-Aware Classification]{Static Hardware-Aware Classification}
\label{sec:6p2}

\noindent Both static studies use the same measured current model, and each puts a different question to it. Dense and
convolutional spiking networks are trained first on \abbrevdef{MNIST} \cite{lecun1998gradient} to establish whether
they can learn through the nonlinear current and fixed device variation. A local firing-rate gate is then added to the
dense architecture, and that comparison tests whether the gate improves generalisation under the same current model.
Within each comparison, the architecture, optimiser, data, and training schedule remain fixed, and only the device
model or the rate gate changes.\\

\noindent Classification uses the full \abbrev{MNIST} split, ten timesteps, twelve epochs, batch size $64$, a
learning rate of $5\times10^{-4}$, and three trained networks per condition. Homeostasis uses a
$6{,}000/2{,}000$ subset, eight timesteps, six epochs, and twenty paired trained networks with the same batch size and
learning rate, and both studies optimise with Adam. The classification study trains membrane outputs at each timestep,
while the homeostasis study trains summed spike counts; their absolute accuracies are therefore reported separately.

\subsection[Classification with the Static Device Model]{Classification with the Static Device
Model}\label{sec:6p2class}

\noindent Two architectures were trained with the static device model in the computational graph
(Figure~\ref{fig:6i}). They differ in topology and in the fraction of synapses represented by memristive devices.\\
\begin{figure}[htbp!] 
    \centering    
    \includegraphics[width=0.75\textwidth]{Chapter6/Figs/msnn_architecture.pdf}
    \caption[Abstract SNN representation for MNIST pattern recognition.]{\emph{Schematic}: \abbrev{SNN} for
    \abbrev{MNIST} classification, showing the input, memristive hidden layers, and output layer.}
    \label{fig:6i}
\end{figure}

\noindent In the dense memristive \abbrev{SNN} (\abbrevdef{MSNN}), $28\times28$ image inputs pass through 100 hidden
\abbrev{LIF} neurons to 10 output neurons, and every synapse uses the device model. The memristive convolutional
spiking network (\abbrevdef{MCSNN}) uses convolutional stages with 12 and 64 filters, $5\times5$ kernels, and
$2\times2$ pooling, followed by a memristive fully connected layer feeding 10 output neurons, while its convolutional
encoder remains digital. Both networks train on $60{,}000$ samples and test on $10{,}000$, with the measured
current model included in the forward and backward passes. Their results are separate evaluations because topology
and memristive coverage both differ.\\

\begin{figure}[htbp!]
    \includegraphics[width=\textwidth]{Chapter6/Figs/training_curves.pdf}
    \caption[Hardware-aware training of the two architectures.]{\emph{Simulated}: test loss and accuracy under ideal
    conductance and the measured Poole--Frenkel response. \textbf{(a,\,b)} Dense \abbrev{MSNN}.
    \textbf{(c,\,d)} Convolutional \abbrev{MCSNN}. Bands show one population standard deviation over three trained
    networks. Both conditions use the full \abbrev{MNIST} split for twelve epochs.}
    \label{fig:6j}

\noindent With ideal synapses the dense network reaches $94.9\%$, and with the measured device model it reaches
$85.8\%$, a $9.2$-percentage-point difference after twelve epochs. Its device-model accuracy peaks at $89.9\%$ after
the first epoch, while its mean test loss falls from $3.85$ to $2.94$, compared with $2.99$ to $1.28$ in the ideal
condition (Figure~\ref{fig:6j}a,b). The convolutional network reaches $97.7\%$ with ideal synapses and $87.3\%$ with
the device model (Figure~\ref{fig:6j}c,d), and its device-model accuracy is still rising at epoch twelve, so the
$10.4$-point difference at that epoch does not establish an asymptotic loss. These simulations extend
nonideality-aware training
\cite{joksas2022nonideality} to spiking architectures and show that both networks learn through the measured current
model. They do not test post-training hardware mapping, circuit energy, or an architectural ranking between the two
networks.

\subsection[Firing-Rate Homeostatic Gain]{Firing-Rate Homeostatic Gain}
\label{sec:6p2p3homeo}

\noindent This second study tests a local firing-rate gate in the same dense architecture, with no injected
conductance faults. Both conditions use the stochastic Poole--Frenkel current model and differ only in whether the
gate is active. Although its form is motivated by the excessive drive caused by a synapse stuck at $G_{on}$
\cite{joksas2020committee, xia2017stuck}, the comparison isolates rate regularisation and makes no claim
about fault recovery.\\

\noindent Each presynaptic spike line is multiplied by a factor computed from that line's recent firing rate
\cite{kim2021spiking, stoffel2024spiking}, which leaves both the conductance and the trained weight unchanged. For
rate $r_{in}$,
\begin{align}
    h(r_{in}) = \frac{1}{1 + \left( \dfrac{r_{in}}{r_{th}} \right)^{n_H}},
    \qquad \widetilde{x}(t) = h(r_{in})\, x(t), \label{eq:6.43}
\end{align}
\noindent the gated train $\widetilde{x}(t)$ replaces $x(t)$ at the downstream layer. The gain is a Hill function of
the firing rate: $r_{th}$ is its half-inhibition constant, the rate at which the gain halves, and $n_H$ is its Hill
coefficient, which sets how sharply the gain falls beyond that rate. With a five-step window, $r_{th}=0.8$, and
$n_H=1$, attenuation reaches the most active lines before their spikes propagate.\\

\noindent That exponent follows from the measured device and not from a chosen sharpness.
Equations~\ref{eq:5.12} and~\ref{eq:5.13} balance field-driven filling against field-free emission, and at the steady
state of that balance the screened fraction is $f/(f+g)$. Letting the filling rate $f$ follow the presynaptic rate
leaves the unscreened fraction $1/(1+r_{in}/r_{th})$, with $r_{th}$ the emission rate divided by the filling gained
per spike. Equation~\ref{eq:6.43} at $n_H=1$ is that expression, so the value follows from a single screening state
and not from the cascade depth fitted in Section~\ref{sec:5p3}. Only the five-step window and $r_{th}=0.8$ remain
simulation settings, held fixed and chosen before the accuracy comparison.\\

    \caption[Architecture of the homeostatic gain regulariser.]{\emph{Schematic}: homeostatic gain in
    \textbf{(a)} the dense network and \textbf{(b)} its array mapping. Input drivers are green, hidden-layer
    amplifiers are blue, and one element controls each output line. The mapping is proposed, not fabricated.}
    \label{fig:6n}

\noindent Figure~\ref{fig:6n} places one gain element on each hidden-layer output line, before the downstream
crossbar sums its current. Because the rate is computed over only five steps, the gate responds to recent high activity

identically, and confidence intervals were bootstrapped from the within-network accuracy differences. The gate
increases mean accuracy by $2.58$\,pp on \abbrev{MNIST} and $4.46$\,pp on Fashion-\abbrev{MNIST}, with both intervals
excluding zero (Table~\ref{table:6homeo}). These paired differences support rate-dependent regularisation of the
presynaptic drive under the nonlinear current model.\\

\noindent The gate acts locally in the forward path, requires no postsynaptic feedback or per-device recalibration,
and was evaluated only in the dense static network. Both studies in this section therefore concern present-input
transmission: the device current responds to each applied voltage but stores no information from earlier activity.
Section~\ref{sec:6p3} adds the measured relaxation and tests the information retained by that volatile state.

\section[Volatile State and Temporal Memory]{Volatile State and Temporal Memory}
\label{sec:6p3}

\noindent Static transmission contains no memory of an earlier input. Both temporal experiments therefore multiply
the static device current by the normalised \abbrev{ITO} relaxation and test classification after an input-free
interval. In the first, one frozen output layer carries either the measured relaxation or an exponential of equal
mean lifetime, so that only the decay profile differs between the two conditions. The second makes every synaptic
layer volatile and removes state from selected layers to identify where delayed information remains.

\subsection[Measured Decay and Numerical Kernel]{Measured Decay and Numerical Kernel}
\label{sec:6p3p1}

\noindent Ten post-drive relaxations were measured by the near-zero-bias read of Section~\ref{sec:3pulse}, from one
\abbrev{ITO}-contacted pad in one session, each extending
for about $226$~s after bias removal. Nine satisfied the kernel screen of Section~\ref{sec:3analysis} and
define the decay used here (Figure~\ref{fig:6t}). This scatter measures within-session
repeatability on one contact, not variation between devices. Delayed-readout tasks are constructed around this
measured timescale because standard classification benchmarks contain no multi-second intervals without input.\\

\begin{figure}[htbp!]
    \centerline{\includegraphics[width=\textwidth]{Chapter6/Figs/ito_kernel_derivation.pdf}}
    \caption[Measured relaxation and the kernel derived from it.]{\textbf{(a)} \emph{Measured}: nine relaxations from
    one \abbrev{ITO}-contacted pad in one session, with stretched-exponential fits. \textbf{(b)} \emph{Measured and
    derived}: floor-subtracted, amplitude-normalised traces with the fitted profile and equal-mean exponential. The
    dashed vertical marks where the measured and equal-mean profiles are equal, at $42.9$~s.
    \textbf{(c)} \emph{Derived}: time constants and weights in Equation~(\ref{eq:6.47}). The traces show within-session
    repeatability on one pad, not variation between devices.}
    \label{fig:6t}
\end{figure}

\noindent After subtracting each fitted floor and dividing by its amplitude, the nine relaxations closely overlap.
Their common normalised decay follows the stretched-exponential form
\begin{align}
    q(t) = \exp\!\left[ -\left( \frac{t}{\tau} \right)^{\!\beta} \right], \label{eq:6.45}
\end{align}
\noindent with aggregate parameters $\tau=16.0$~s and $\beta=0.622$, the leakage scale and exponent of
Equation~\ref{eq:3.1} aggregated over the nine relaxations into one fitted profile. Because $\beta<1$, early loss is
faster and the late tail slower than for a single exponential. Equation~\ref{eq:6.45} acts as the synaptic kernel:
it multiplies the static device current by the fraction of written state remaining after time $t$, with no
additional fitted amplitude. Measured amplitudes span a factor of $1.87$, while the normalised shapes remain
closely aligned.\\

\noindent This fitted leakage scale sits well above the field-free discharge of order a few seconds obtained in
Section~\ref{sec:5p-ito} for the same relaxation, and the two estimates do not rest on the same footing.
That earlier estimate extrapolates a held-bias fit to zero field; this kernel is fitted directly to the post-drive
decay. Length of observation moves the fit as well: on these same measurements, $30$~s and $226$~s fitting intervals
return $\beta=1.07$ and $0.622$. Protocol and observation length therefore both separate the two estimates, and
neither is shown to account for the whole difference.\\

\noindent Analytically, the fitted profile has a mean lifetime of
$\langle t\rangle=(\tau/\beta)\Gamma(1/\beta)=23.0$~s, while the numerical approximation used for recursive
simulation has a mean lifetime of $23.4$~s. The exponential comparator introduced below is matched to this
implemented value, so the two simulated profiles have equal total retained state over time and differ in decay
shape.\\

\noindent A non-negative weighted sum of ordinary exponentials permits recursive state updates:
\begin{align}
        q(t) \simeq \sum_{i} w_i \exp\!\left( -\frac{t}{\tau_i} \right), \qquad w_i \geq 0, \qquad \sum_i w_i = 1.
    \label{eq:6.47}
\end{align}
\noindent This sum reproduces the fitted profile over the simulated range with $R^2=0.99997$. One network step is
$0.4525$~s, the mean sampling interval of the measured relaxation, and no component decays faster than this step.
Its time constants provide a numerical representation of dispersive decay and are not identified microscopic trap
lifetimes. Their weighted sum falls faster than an equal-mean exponential at early times and more slowly at late
times (Figure~\ref{fig:6vso}).\\

    \centerline{\includegraphics[width=\textwidth]{Chapter6/Figs/volatile_synapse_origin.pdf}}
    \caption[Why a volatile crosspoint can carry information across a gap.]{\emph{Conceptual schematic}.
    \textbf{(a)} A simulated SiO$_x$ crossbar carries the decay shape measured at an \abbrev{ITO}
    contact. Driven rows leave fading state that a later probe reads. \textbf{(b)} A distribution of release barriers
    gives a distribution of rates. \textbf{(c)} Their weighted sum decays faster than an equal-mean exponential at
    first and more slowly at late times. No microscopic trap energies are identified.}
    \label{fig:6vso}
\end{figure}

\noindent Static and volatile behaviour enter the simulation from separate measurements: the Ti/Au measurements
supply the static Poole--Frenkel current, conductance mapping, and fixed device variation, and the \abbrev{ITO}
measurements supply only the normalised multiplier $q(t)$. Both comparison conditions use the same static model,
device realisation, and mapped weights, so equal values of $q(t)$ give equal currents and only the decay profile
changes. This multiplier acts on each device current before subtraction of the differential pair, allowing device
mismatch to remain in the output. It represents synaptic state and does not alter the neuronal time constant in
Equation~\ref{eq:6.1}. No fabricated device in this work combines both measured functions.

\subsection[Decay Shape Sets Usable Delay]{Decay Shape Sets Usable Delay}
\label{sec:6p3p2}

\begin{figure}[htbp!]
    \centering
    \includegraphics[width=\textwidth]{Chapter6/Figs/pretrain_map_freeze.pdf}
    \caption[Training, mapping and the fixed comparison are separated.]{\emph{Schematic}. \textbf{(a,\,b)} Each
    network trains with an ideal, non-volatile output layer. \textbf{(c)} Mapping of the output matrix occurs once,
    and one read-current conversion is calibrated from $256$ unlabelled zero-hold samples pooled across both
    profiles. This fixed network is then evaluated under the measured decay and the equal-mean exponential.}
    \label{fig:6pmf}
\end{figure}

\noindent Both temporal architectures differ from the static networks: the dense model maps 578 inputs to 64 hidden
neurons and then through a volatile $64\rightarrow10$ output synapse. The convolutional model uses two $3\times3$
stages with 4 and 8 channels, each stage followed by $2\times2$ max pooling and \abbrev{LIF} neurons, and its 32
features feed a volatile $32\rightarrow10$ output synapse. The encoder layers are ideal in both cases, leaving one
fading layer between the stimulus and class decision.\\

\noindent Each \abbrevdef{N-MNIST} sample supplies eight $2\times17\times17$ event frames, one frame per $0.4525$~s
device update, and this assignment replaces the dataset's native timing to give a presentation of about $3.6$~s.
Five networks per architecture are trained on $8{,}000$ samples, with $2{,}000$ reserved for validation and early
stopping. Training uses an ideal, non-volatile output layer with no hold or probe. After training, the learned output
matrix is mapped once onto the volatile layer without retraining (Figure~\ref{fig:6pmf}).\\

\noindent One read-current conversion carries the measured current into the neuronal input, and it is calibrated once
across both decay profiles from 256 unlabelled training samples read at zero added hold. Writing $I_{rj}$ for the
current at probe step $r$ on output neuron $j$, the input to that neuron is
\begin{align}
    u_{rj} = A\,\frac{I_{rj} - \mu_{rj}}{s} + C,
    \label{eq:6conv}
\end{align}
\noindent where $\mu_{rj}$ is the mean calibration current at that probe step and neuron, $s$ is a scale shared by
both profiles, $A$ is a gain, and $C$ is an offset. The mean is taken separately for each probe step and neuron
because the current falls during the twelve-step readout and differs between output neurons, so one pooled mean would
leave a step-dependent offset in the input. Both profiles adopt the larger of their two values of $s$, which holds
the narrower profile inside the same input range instead of rescaling it against its own spread. The gain and offset
follow from a bounded iteration that brings spike counts to a mean of six of the twelve probe steps with a spread of
three, the range in which a count still discriminates: near zero or twelve the counts saturate and ties decide the
class.\\

\noindent The calibration samples contribute equally under both profiles, and no test data enter it. Once calibrated,
the weights, device realisation, and conversion remain fixed for every profile and delay, so substituting the
equal-mean exponential for the measured relaxation changes only the temporal state retained by one fixed network.\\

\noindent During evaluation, eight frames write the volatile state, no input is applied for an added delay $D$, and a
common probe reads the remaining state for twelve steps. This probe supplies the voltage required to measure current
but does not modify the simulated state or carry sample-specific information. Membrane states are reset before
readout, and output spike counts select the class; ties are resolved by the largest final membrane potential among
the tied classes.\\

\noindent Thirteen requested delays spanning $0$--$226$~s were rounded to the device update interval, giving the grid
used throughout,
\begin{align}
    D \in \{ &0,\, 1.81,\, 4.07,\, 8.15,\, 15.84,\, 23.08,\, 32.13, \nonumber \\
    &\quad\, 44.80,\, 63.80,\, 90.05,\, 128.06,\, 180.10,\, 225.80 \}~\mathrm{s},
    \label{eq:6grid}
\end{align}
\noindent where $D=0$ means no added hold after the complete sample rather than an instantaneous read. Because the
eight frames were written at different times and the probe lasts twelve steps, the contributions reaching the output
have elapsed times from $D+0.45$ to $D+8.60$~s when the probe begins, and up to a further twelve steps by the time it
ends. Accuracy is evaluated on $2{,}000$ held-out samples at every delay with three read-noise repetitions.\\

\noindent Usable delay, $D_{\max}$, is the added delay at which accuracy retains a fixed fraction $f$ of its
zero-hold margin above the majority-class baseline:
\begin{align}
    a_{\mathrm{threshold}} = a_{\mathrm{floor}} + f\left( a_{0} - a_{\mathrm{floor}} \right), \qquad f = 0.75,
    \label{eq:6.48}
\end{align}
\noindent where $a_0$ is zero-hold accuracy and $a_{\mathrm{floor}}=11.3\%$ is the majority-class rate. Fixing
$f=0.75$ before replay, the primary analysis computes a separate threshold for each profile, so $D_{\max}$ measures
retention of that profile's own starting margin. Isotonic regression by pooling adjacent violators gives a
non-increasing accuracy--delay curve \cite{ayer1955empirical}, and linear interpolation locates its threshold
crossing. A profile whose zero-hold accuracy does not exceed the
one-sided $95\%$ Clopper--Pearson chance limit receives $D_{\max}=0$ \cite{clopper1934confidence}.\\

\noindent The comparison uses
$\Delta D_{\max}=D_{\max}^{(\mathrm{measured})}-D_{\max}^{(\mathrm{exponential})}$, in which negative values mean
that the equal-mean exponential supports the longer delay. All five prespecified networks per architecture entered
the analysis, and repeated read-noise evaluations are averaged within each network before Student-$t$ intervals are
calculated across networks. A denser delay grid changes $\Delta D_{\max}$ by less than $0.2$~s.\\

\noindent Zero-hold accuracies differ by less than $0.3$ percentage points: $87.7$--$88.0\%$ in the dense networks
and $79.5$--$79.8\%$ in the convolutional networks. The shared conversion therefore places both profiles within the
same readout range, and the comparison begins from equal accuracy. The equal-mean exponential then supports the
longer usable delay in both architectures, by $5.3$~s in the dense networks and $6.4$~s in the convolutional
networks, and the sign is negative in every one of the ten trained networks (Table~\ref{tab:6dmax} and
Figure~\ref{fig:6dad}a,\,b).\\

\noindent The two implemented profiles share a mean lifetime of $23.4$~s but distribute it differently: their
half-lives are $9.18$~s and $16.2$~s and their $1/e$ times $16.4$~s and $23.4$~s, all four evaluated on the

delay of a fixed network.\\

\begin{figure}[htbp!]
    \centerline{\includegraphics[width=\textwidth]{Chapter6/Figs/frozen_substitution_delay.pdf}}

\noindent Three controls remove the information carried by the volatile state while preserving the trained network
and readout. At $D=4.07$~s, clearing the written state before the probe gives exactly the same result as skipping the
write, with accuracies of $8.80$--$11.25\%$ across the ten networks, all below the $12.53\%$ chance bound. Removing the
volatile current contribution keeps accuracy below that bound over the complete delay grid and gives
$D_{\max}=0$. Because membrane states are reset before every probe, the volatile output-layer state is the only
sample-dependent quantity spanning the interval.\\

\noindent The equal-mean profiles cross at $42.9$~s: before that time the exponential retains more state, and
afterwards the measured profile retains more because its tail decays more slowly. At $f=0.75$, the oldest
contributing state at $D_{\max}$ is $38.4$~s in the dense architecture and $32.9$~s in the convolutional
architecture, placing both decisions before the crossing. The exponential therefore supports the longer usable delay
at the primary criterion.\\

\noindent Lowering $f$ admits a later part of the accuracy curve and eventually makes the measured profile's slower
tail relevant. Averaged across networks, $\Delta D_{\max}$ changes from negative at high $f$ to positive below
approximately $0.4$ (Figure~\ref{fig:6dad}c). The criterion therefore selects which part of the decay the task reads,
and it is a property of the task and its readout and not of the device. Because both profiles share the conversion of
Equation~\ref{eq:6conv} and take the larger of their two scales, this reversal cannot arise from separate readout
scaling.\\

\noindent Neither the leakage scale nor the mean lifetime alone specifies a volatile synaptic state once $\beta$ is
free to vary. The fitted $\tau$ and $\beta$, the complete normalised decay, and the conditions under which it was
measured together determine how much state survives to a task-relevant delay. The differences measured here apply to
one \abbrev{ITO} contact, one volatile output layer, and the two simulated architectures tested.

\subsection[Volatile State Across Layers]{Volatile State Across Layers}
\label{sec:6p3p3}

\noindent Where the output-layer substitution isolates decay shape in one synapse, the all-layer experiment applies
the measured relaxation to every synaptic layer. The evaluation after a $4.07$~s input-free interval tests which
retained states still contribute to classification. This experiment introduces no alternative decay: each trained
network is compared with itself after selected volatile states are removed, so the conditions differ only in which
layers still hold state when the probe arrives.\\

\noindent Each fading layer changes the input received by the next, so the operating points are calibrated
sequentially before training. A label-free bisection sets one frozen output offset per layer to produce a firing
fraction of $0.15\pm0.02$ over the twelve-step read, and each calibrated layer is fixed before the next is placed.
No class labels or accuracy target enter this procedure, so the calibration cannot import information about the
classification task. Networks train with no hold and are frozen before the evaluation delay is introduced, preventing
the weights from adapting to that delay.\\

\noindent All interventions start from the same state snapshot at the end of the hold

\noindent On \abbrev{N-MNIST} \cite{orchard2015nmnist}, both architectures classify well above chance after the

of clearing.\\

\noindent Clearing any single layer costs accuracy in every one of the five networks of each architecture, whereas retaining any single

contribute comparably when cleared, between $39.5$ and $45.6$ points, and none of them alone separates from that
control. Necessity without sufficiency in either architecture places the delayed decision on volatile state
distributed across layers rather than held in any one of them.\\

\section[Summary]{Summary}\label{sec:6p4}

\noindent The electroformed Ti/Au measurements enter the networks as static synaptic transmission: a conductance
window, nonlinear current response, and fixed device variation. Dense and convolutional spiking networks learn under
this measured forward model, and a local firing-rate gate improves generalisation in the dense network without
injected faults.
These results concern hardware-aware optimisation under static device properties; they do not establish circuit
efficiency or local learning.\\

\noindent The \abbrev{ITO} relaxation enters as a volatile synaptic state that carries class information across an
input-free interval, and removing that state returns performance to chance. An exponential with the same mean lifetime
supports $5.3$~s and $6.4$~s more usable delay at the prespecified $f=0.75$ criterion, because the readout depends on
the early decay. Lower values of $f$ reach the measured profile's slower tail and can reverse the ordering. A single
retention time therefore does not specify task memory: a volatile synapse has to be described by its complete decay
profile, timescale and shape together.
Layer interventions further show that delayed classification uses volatile state distributed across the network.
This chapter's biorealistic element is therefore the measured material relaxation that sets the temporal state, while
weight optimisation still uses surrogate gradients and transported errors.
